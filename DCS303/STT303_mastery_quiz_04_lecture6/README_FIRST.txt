STT303 Mastery Quiz 4
Lecture 6: Importing and Inspecting Data
Suggested time: about 20 minutes

BEFORE THE QUIZ
1. Extract/unzip the entire folder.
2. Open STT303_mastery_quiz_04.Rproj in RStudio.
3. Open mastery_quiz_04.R.
4. Do not edit grade_this.R.

REQUIRED PACKAGES
The quiz uses:
  here
  readr
  dplyr
  skimr
  readxl

If needed, install them BEFORE the quiz:
install.packages(c("here", "readr", "dplyr", "skimr", "readxl"))

TO CHECK YOUR WORK
Save mastery_quiz_04.R, then run in the Console:

source("grade_this.R")
grade_this()

The grader:
- checks Problem 1, then Problem 2, and so on;
- awards partial credit within each problem;
- gives feedback on individual components;
- continues to later expressions when possible even if one expression errors.

SUBMIT
Submit mastery_quiz_04.R only unless instructed otherwise.
